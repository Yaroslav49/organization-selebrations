# Веб-сайт "ЗаЕду на праздник"

Командный проект, где я делал фронтенд на Angular. Проект представляет собой сайт для поиска организаторов праздников.
- Реализовал интерфейсы по работе с заказами для мастера и клиента.
- В работе использовал библиотеку Taiga UI, начиная от полей ввода TuiInput и заканчивая сложными компонентами вроде TuiAccordion и TuiDialog.
- Реализовали в проекте интеграцию с MinIO, где хранились изображения.
- Поработал с токеном jwt и перехватчиком запросов HttpInterceptor, которые использовались для авторизации пользователей.
- Для контроля доступа к маршрутам использовал интерфейс CanActivateFn.
